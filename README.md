# Overview
This Minecraft Mod revamps the vanilla enchantment system. Now, all you need to do is attack mobs, and the item in your hand will gain enchantments automatically. Additionally, we’ve introduced several exciting new items to enhance your gameplay.

# Features
- **Random-Enchantment**: Attack mobs to randomly gain enchantments on your items
- **EnchantBrush**: Select areas to enchant multiple blocks at once
- **Pearl Spear**: Unique weapon with combo skills and custom animations

# Installation
- **Minecraft**: 1.21.1
- **NeoForge**: 21.1.216+
- Place mod JAR in `mods` folder

# Quick Start
1. `/random_enchant doRandomEnchant true` - Enable Random Enchantment
2. `/random_enchant description` - View mod info
3. Use EnchantBrush to select and enchant block areas
4. Find Pearl Spear for special combat skills

# Commands
- `/random_enchant description` - Mod information
- `/random_enchant doRandomEnchant <true/false>` - Toggle auto-enchant

# New Items
- **EnchantBrush**: Enchant areas of blocks
- **Pearl Spear**: Spear with combo skills and enchantment synergy

# Custom Enchantments
- Fury Of Fly: Summon powerful bees to help you

# Compatibility
Works with most mods. May conflict with major enchantment overhauls.
